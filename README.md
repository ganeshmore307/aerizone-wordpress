# Aerizone WordPress Website

Custom website source for [Aerizone Automation & Security Systems](https://aerizone.in/).

## Website pages

- Home
- About
- Services

## Deployment

This repository will be connected to the GitHub to WordPress Sync plugin installed on `aerizone.in`.
